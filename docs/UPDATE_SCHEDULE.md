# 每日更新排程

GitHub Actions 於台灣交易日執行下列六次更新：

| 台灣時間 | 目的 |
| --- | --- |
| 14:50 | 抓取三大法人初步盤後資料 |
| 15:00 | 補抓期貨未平倉資料 |
| 15:05 | 再次確認法人與期貨資料 |
| 21:30 | 抓取信用交易完整資料 |
| 21:35 | 再次確認信用交易資料 |
| 21:40 | 最後補抓當日完整版本 |

若官方尚未提供當日上市資料，或當日休市，更新程式不會覆寫
`data/latest/market-dashboard.json`，網站會保留前一個交易日資料。

GitHub 排程可能延遲數分鐘；頁面上的資料完整度標籤表示更新批次的預定資料範圍。
