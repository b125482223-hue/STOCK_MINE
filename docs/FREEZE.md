## 已知限制

- GitHub Actions 排程沒有準時執行保證，實際可能延遲數小時。
- 新日期的整體融資維持率沒有可用的同份官方公開統計，因此顯示 `--`。
- 法人買賣金額是以買賣超股數乘收盤價估算。
- 外部官方 API 若調整欄位或服務，更新工作流程可能失敗；網站會維持最後成功資料。

後續變更應以新功能或資料來源修正為獨立工作，不直接重構本 MVP 的既有資料契約。
