# MVP Scope

## 目標

建立一個可部署到 GitHub Pages 的台股籌碼與指數靜態儀表板，讓使用者用瀏覽器快速查看大盤與櫃買三大法人買賣超、融資融券、期貨未平倉與目前指數。

## 本階段包含

- 單頁 HTML 儀表板。
- 低飽和藍白色系、卡片式資訊區塊、表格優先。
- 以 `config/data_sources.json` 管理資料來源。
- 以前端 `fetch()` 讀取官方公開資料。
- API 失敗時使用 sample fallback。
- 三大法人買賣超只顯示大盤與櫃買市場合計，不顯示個股排行。
- 顯示資料狀態：即時、範例、錯誤、最後更新時間。

## 本階段不包含

- 登入、會員、個人化設定。
- 後端伺服器。
- 資料庫。
- 投資建議或交易訊號。
- 付費資料源。
- 大量歷史回測。

## 驗收條件

- 直接開啟 `index.html` 或透過本機靜態伺服器可看到儀表板。
- 四個核心區塊存在：三大法人市場合計、融資融券、期貨未平倉、指數。
- 官方 API 失敗時仍能顯示 sample fallback。
- 頁面清楚標示資料來源狀態與最後更新時間。
- README 有 Windows / PowerShell 使用與 GitHub Pages 部署步驟。

## 第二階段候選

- GitHub Actions 定時抓取官方資料並生成 `data/latest/*.json`。
- 期交所未平倉資料源穩定化。
- 指數盤中更新頻率與資料延遲標示。
- 匯出 CSV。
- 自選股篩選。
